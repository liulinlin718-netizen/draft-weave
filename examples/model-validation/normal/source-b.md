# 耳伴解说服务方案

本稿为虚构业务测试材料，仅为模型验收准备输入，未执行任何试点或模型请求。

## 试行安排

展馆语音导览应帮助观众按自己的节奏理解展品，而不是把参观变成连续收听的任务。

耳伴服务先提供围绕展品展开的简短说明，再允许观众继续了解策展背景。随身讲解的名称同时出现在借用卡和展柜说明上，团队尚未统一面向观众的称呼。

工作人员先展示借用卡，再指向展柜上的扫码说明。它需要让观众知道如何暂停和继续播放；如果观众不想使用自己的手机，设备借用流程也应保持可见。说明内容与领取路径在这里交叉出现。

设备交还后，前台记录操作中断的位置，并把记录交给内容编辑。它不能替代观众的解释，工作人员仍需询问观众为何停止收听，避免把所有中断都当成内容不够吸引人。

试行期间，策展团队根据收集到的问题补充解释，前台根据借还现场的反馈调整提示。两边各自处理问题，现有稿件还没有说明它们如何共同决定需要修改的环节。
