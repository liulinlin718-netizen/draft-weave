# 观众导览复盘

本稿为虚构业务测试材料。下述评估安排是供审阅的方案，不是已获得的效果结论。

## 复盘与后续

后台播放记录要与现场交流放在一起阅读。播放完成不代表观众理解了内容，中途退出也不必然代表体验失败；有人可能已经获得所需信息，也有人只是暂时离开展柜。

复盘时，应把设备借还、展柜入口与音频内容放进同一段参观经历中讨论。团队需要辨认困难发生在哪里，再决定由前台修改提示，还是由编辑调整说明，不能仅凭播放次数决定全部改动。

移动听展的下一步是让观众更容易做出选择。继续收听、暂停观察或结束导览都应是自然的参观方式。保留这些选择的前提，是内容和现场服务能够共同回应同一个问题，而不是分别追求自己的完成量。
