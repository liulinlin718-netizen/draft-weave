# 让一次改造成为持续的服务

## 复盘方法

社区图书馆不只是借书的地方，也是居民在日常生活中重新连接知识与彼此的入口。

试点复盘应回到最初的服务问题：居民是否更容易找到需要的书，馆员是否有余力回应咨询，志愿者是否知道自己的职责。将这些问题分开记录，再放在一起讨论，才能避免用一次热闹活动代替完整判断。

### 收集不同经历

除已经参加活动的居民外，团队也应邀请没有进门、没有借到书或中途离开的居民表达看法。他们的经历可能揭示导视、时间安排与服务方式之间的断点，而这些断点往往不会出现在满意度留言中。

对仍有争议的做法，可以保留原有服务与试行服务的差异记录。讨论时先解释各自解决的问题，再决定保留、调整还是停止。能够说明停止的原因，与能够展示成功的经验同样重要。

## 结语

从空间更新走向服务改造，关键是让居民的具体经历进入日常决策。每一次调整都应有明确的回应对象，也有可以回看与修正的依据。图书馆因此获得的，不只是一套更清楚的流程，还有与社区持续对话的能力。

当居民愿意再次走进来、馆员能够从容回应、志愿者知道如何协作，改造才真正发生。我们不必等待一个完美方案落成；先把眼前的一次到访照顾好，再让这些可重复的小改变逐渐成为社区的习惯。
